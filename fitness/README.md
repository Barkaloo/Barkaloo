# Barkaloo / Training

Прототип учёта спортивных тренировок на основе английского Barkaloo: исходные стили, иллюстрации светлой/тёмной темы, персонаж, боковая навигация, календарь на главной, шесть карточек статистики и отдельный экран прогресса.

```sh
python3 -m http.server 8001 --bind 127.0.0.1 --directory /workspace/Barkaloo
```

Фитнес-прототип находится по пути `/fitness/`. Сборка и установка зависимостей не нужны. Для статического размещения достаточно содержимого папки `fitness`.

- Главная: календарь с тренировочными днями, статистика за выбранный период, недельная цель, последние записи, экспорт и восстановление резервной копии JSON.
- Тренировки: добавление, редактирование, удаление, поиск и фильтрация по виду спорта.
- Прогресс: переключаемые графики времени, количества тренировок, дистанции и активных дней; периоды 7/30/90 дней; таблица исходных значений и распределение времени по видам тренировок.
- Тема: системная, светлая или тёмная. Разделы поддерживают прямые hash-ссылки и историю браузера.

Данные сохраняются в localStorage этого браузера. Ключ `ritm.workouts.v1` сохранён для совместимости с предыдущим прототипом. Облачная синхронизация и учёт подходов/повторений/веса пока не реализованы; упражнения можно описать в заметках. Тренировки в будущем не записываются. Периоды включают текущий локальный день; недельная цель считается с понедельника; серия активности — последовательные дни до сегодняшнего включительно. Демоданные добавляются по кнопке только в пустой журнал.

`barkaloo.css` содержит перенесённые стили `source/app.html`. Встроенные PNG-фоны вынесены в `assets/background-1.png` и `assets/background-2.png`; `assets/logo.png` скопирован из `source/logo-character.png`. `style.css` содержит дополнения для спортивных данных. Внешние шрифты и CDN не требуются.

Английский Barkaloo и его данные не изменены. `node build.cjs` также копирует фитнес-прототип в `dist/fitness/` для публикации в существующем Vercel-проекте по пути `/fitness/`.
